High-Dimensional Sharp Lipschitz Convex Minimization

We minimize a convex Lipschitz function f:Rd→R in high dimension d. Its objective gap grows at least linearly with Euclidean distance to the minimizer set. A given starting point x0 lies within a prescribed radius of a minimizer x⋆. At each query x, the oracle returns f(x) and a subgradient selected by a fixed function of x. For a tolerance ε>0, the goal is an output x¯∈Rd with integrable objective gap satisfying E[f(x¯)−f(x⋆)]≤ε, where the expectation is over the algorithm’s randomness.

The optimization problem is minx∈Rdf(x). Write X⋆ for the set of global minimizers and ∥⋅∥ for the Euclidean norm. The algorithm receives the dimension d∈N, the Lipschitz constant L, the sharpness constant μ, the initial radius D, the tolerance ε, and the starting point x0∈Rd.

Our assumptions:

Assumption 1 (Parameter regime and dimension). The parameters satisfy μ>0, L≥96μ, D>0, and 0<ε≤μD. With κ=L/μ and r=μD/ε, the dimension satisfies d≥210(1+κ2(1+log⁡r))6(κr)2, where log denotes the natural logarithm.

Assumption 2 (Convexity and Lipschitz continuity). For all x,y∈Rd and t∈[0,1], f((1−t)x+ty)≤(1−t)f(x)+tf(y),|f(x)−f(y)|≤L∥x−y∥.

Assumption 3 (Initial distance and sharpness). There exists x⋆∈X⋆ with ∥x0−x⋆∥≤D. For every x∈Rd there exists z∈X⋆ such that f(x)−f(z)≥μ∥x−z∥.

At any query x∈Rd, the oracle returns (f(x),g(x)), where the fixed map g:Rd→Rd satisfies f(y)≥f(x)+⟨g(x),y−x⟩for all x,y∈Rd. After the allotted oracle calls, the output x¯ must satisfy f(x¯)−f(x⋆)∈L1(P),EP[f(x¯)−f(x⋆)]≤ε, where P is the law of the algorithm’s randomness.

  • Sharp Lipschitz Convex Lower Bound · Lean proof

Let f:Rd→R be convex and L-Lipschitz, with a minimizer within D>0 of x0 and global sharpness f(x)−f⋆≥μdist(x,arg⁡minf) for μ>0. Each call returns the exact value and a fixed subgradient at the query. The target is an integrable gap with E[f(x^)−f⋆]≤ε, over algorithm randomness. The setup requires κ≥96, 0<ε≤μD, and d≥210(1+A)6(LD/ε)2.
