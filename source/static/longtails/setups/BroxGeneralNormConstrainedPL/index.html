Constrained Polyak–Łojasiewicz Minimization

We consider minimizing a possibly nonconvex function f:E→R over a closed convex set C in a finite-dimensional real normed space E. On C, the objective is bounded below, has a Lipschitz derivative, and satisfies a constrained Polyak–Łojasiewicz inequality. A given feasible point has bounded initial objective gap. At feasible points, one oracle returns the exact derivative and another returns a minimizer of a supplied linear functional over the intersection of C with a query ball centered at the point. For a tolerance ε>0, the goal is an output x¯∈C satisfying f(x¯)−infz∈Cf(z)≤ε almost surely.

Write f⋆ for the value of the problem infx∈Cf(x). The algorithm receives only E, the smoothness constant L>0, a radius parameter r>0, and the starting point x0. The Polyak–Łojasiewicz constant μ>0, the initial gap bound Δ∈R, and ε may enter the oracle-call budgets. Write E∗ for the continuous dual of E and ∥⋅∥op for its induced operator norm.

Our assumptions:

Assumption 1 (Feasibility and initial gap). The set C is closed and convex, x0∈C, and f⋆>−∞,f(x0)−f⋆≤Δ.

Assumption 2 (Smoothness on the feasible set). The function f is Fréchet differentiable at every x∈C. Its derivative Df(x)∈E∗ satisfies ∥Df(y)−Df(x)∥op≤L∥y−x∥,x,y∈C.

Assumption 3 (Constrained Polyak–Łojasiewicz inequality). For x∈C, define the normal cone and stationarity residual by NC(x)={n∈E∗:n(z−x)≤0 for all z∈C},sC(x)=infn∈NC(x)∥Df(x)+n∥op. The objective satisfies μ(f(x)−f⋆)≤12sC(x)2,x∈C.

Derivative calls and local linear minimization calls are counted separately. The derivative oracle returns Df(x) at x∈C. A local linear minimization query specifies a center x∈C, any radius ρ≥0, and a functional g∈E∗. The oracle returns a point v∈argminz∈C, ∥z−x∥≤ρg(z). After the allotted calls, the output must satisfy x¯∈Candf(x¯)−f⋆≤εP-a.s., where P is the joint law of the independent algorithm and oracle randomness.

  • Warm Halving Brox General Norm · Lean proof

In a finite-dimensional real normed space, C is closed and convex and x0∈C. The objective is bounded below on C and differentiable at each point of C, with L-Lipschitz derivative in the dual norm. On C, μ(f(x)−f⋆)≤s(x)2/2. The oracles give exact gradients and exact local LMOs with arbitrary tie-breaking. For L,μ,r,ε>0, the target, guaranteed almost surely, is x∈C with f(x)−f⋆≤ε.
