High-Dimensional Stochastic Nonconvex Stationarity

We seek an approximate stationary point of a possibly nonconvex function f:Rd→R in a high-dimensional regime. The function is three times continuously differentiable, with globally Lipschitz derivatives of orders one through three. Its value at a given starting point x0∈Rd lies within a prescribed gap of its infimum. Each oracle call uses a fresh independent sample to return an unbiased gradient estimate with uniformly bounded mean squared error. For a tolerance ε>0, the goal is a measurable output x¯∈Rd satisfying E∥∇f(x¯)∥≤ε, averaging over oracle and algorithm randomness.

The underlying optimization problem is infx∈Rdf(x). The algorithm receives the dimension d∈N, the starting point x0, the smoothness constants L1,L2,L3>0, the noise bound σ≥0, the initial gap bound Δ, and the tolerance ε. To specify the parameter regime, set M=min{L1ε,L2ε,L3ε3}. The gap bound and dimension satisfy ΔM≥270ε,d≥2140(1+ΔMε(1+σ2ε2))4.

Our assumptions:

Assumption 1 (Lipschitz derivatives). The function f belongs to C3(Rd). For all x,y∈Rd, ∥∇f(x)−∇f(y)∥≤L1∥x−y∥,∥∇2f(x)−∇2f(y)∥op≤L2∥x−y∥,∥∇3f(x)−∇3f(y)∥op≤L3∥x−y∥. Here ∥⋅∥ is the Euclidean norm and ∥⋅∥op denotes the induced operator norm.

Assumption 2 (Initial objective gap). The starting point satisfies f(x0)−infx∈Rdf(x)≤Δ.

Assumption 3 (Stochastic gradient oracle). At query x∈Rd on call k, the oracle returns g(x,ξk), where g:Rd×R→Rd is jointly measurable. The real-valued random variables (ξk)k≥1 are independent with common law μ, and the sequence is independent of the algorithm’s randomness. For every x∈Rd and ξ∼μ, the vector g(x,ξ) is Bochner integrable, the squared error ∥g(x,ξ)−∇f(x)∥2 is integrable, and Eξ∼μ[g(x,ξ)]=∇f(x),Eξ∼μ[∥g(x,ξ)−∇f(x)∥2]≤σ2.

After the allotted oracle calls, the output x¯ must be measurable and ∥∇f(x¯)∥ must be integrable under the joint law P of the algorithm’s randomness and the oracle samples. The accuracy requirement is EP[∥∇f(x¯)∥]≤ε.

Proved result

⌊Δ⋅min{L1ε,min{L2ε,(L3ε)13}}⋅(1+σ2ε2)2174⋅ε⌋+
