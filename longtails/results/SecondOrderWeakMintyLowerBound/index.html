High-Dimensional Weak Minty Root Finding

We seek an approximate zero of a Lipschitz map F:Rd→Rd with a Lipschitz Jacobian, where d is the dimension. A given starting point lies within a prescribed radius of a zero x⋆ satisfying the weak Minty inequality ⟨F(x),x−x⋆⟩≥−(ρ/2)∥F(x)∥2 at every point x, with ρ≥0. At each query point, the oracle returns either the exact value of F or its exact Jacobian, as requested. For a tolerance ε>0, the goal is an output x¯∈Rd with integrable residual norm satisfying E∥F(x¯)∥≤ε over the algorithm’s randomness.

In residual form, the problem is minx∈Rd∥F(x)∥. We use the Euclidean norm and inner product, and ∥⋅∥op denotes the induced operator norm. The algorithm receives the dimension d∈N, starting point x0∈Rd, Lipschitz bounds L1,L2>0, weak Minty parameter ρ∈[0,1/L1], radius R>0, and tolerance ε. These parameters lie in the regime M=min{L2R2ε,L12R2ε2},215≤M,M3≤d.

Our assumptions:

Assumption 1 (Lipschitz map and Jacobian). The map F is Fréchet differentiable everywhere. Its Jacobian J(x) is a linear map from Rd to Rd. For all x,y∈Rd, ∥F(x)−F(y)∥≤L1∥x−y∥,∥J(x)−J(y)∥op≤L2∥x−y∥.

Assumption 2 (Weak Minty zero and initial distance). There exists x⋆∈Rd with F(x⋆)=0 and ∥x0−x⋆∥≤R such that, for every x∈Rd, ⟨F(x),x−x⋆⟩≥−ρ2∥F(x)∥2.

At any x∈Rd, a value query returns (F(x),0) and a Jacobian query returns (0,J(x)). Both query types count toward a single call budget. After the allotted calls, the output x¯∈Rd must have P-integrable residual norm and satisfy EP[∥F(x¯)∥]≤ε, where P is the law of the algorithm’s randomness.

Proved result

⌊min{L2⋅R2ε,L12⋅R2ε2}215⌋+
