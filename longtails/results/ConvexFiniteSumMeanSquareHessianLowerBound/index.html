Second-Order Convex Finite-Sum Minimization

We minimize a convex function F on Rd, the average of n twice continuously differentiable components. Their Hessians are Lipschitz in root mean square with constant H≥0, and a global minimizer x⋆ satisfies ∥x⋆∥≤R for a radius R>0. The oracle returns the value, gradient, and Hessian of a chosen component at a queried point. For a tolerance ε>0, the goal is a measurable output x¯∈Rd with integrable objective gap satisfying E[F(x¯)−F(x⋆)]≤ε, where the expectation is over the algorithm’s randomness.

Writing fi:Rd→R for component i, define F(x)=1n∑i=1nfi(x). The optimization problem is minx∈RdF(x). The algorithm receives n,d,H,R,ε. The component count n and dimension d are positive integers in the regime K=⌈(HR3nε)2/7⌉,d≥2170n3(1+K)12. We use the Euclidean norm ∥⋅∥ and its induced operator norm ∥⋅∥op.

Our assumptions:

Assumption 1 (Convexity and minimizer radius). For all x,y∈Rd and t∈[0,1], F((1−t)x+ty)≤(1−t)F(x)+tF(y). There exists x⋆∈Rd with ∥x⋆∥≤R such that F(x⋆)≤F(x) for every x∈Rd.

Assumption 2 (Mean-square Hessian regularity). Each fi is twice continuously differentiable. For all x,y∈Rd, 1n∑i=1n‖∇2fi(x)−∇2fi(y)‖op2≤H2∥x−y∥2.

A query specifies any i∈{1,…,n} and x∈Rd and returns the exact triple (fi(x),∇fi(x),∇2fi(x)). After the allotted oracle calls, the output x¯ must be measurable, its objective gap must be integrable, and it must satisfy E[F(x¯)−F(x⋆)]≤ε.
