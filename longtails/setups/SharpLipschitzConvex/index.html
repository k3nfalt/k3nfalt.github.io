Sharp Lipschitz Convex Minimization

We minimize a convex, L-Lipschitz function f:Rd→R in Euclidean dimension d≥0. Its objective gap is at least μ times the distance to the minimizer set, where 0<μ≤L. A given starting point x0 lies within distance D>0 of a minimizer x⋆. At each point x, the oracle returns f(x) and a fixed choice of subgradient. For a tolerance ε>0, the goal is an output x¯∈Rd with integrable gap and E[f(x¯)−f(x⋆)]≤ε, where the expectation is over the algorithm’s randomness.

The optimization problem is minx∈Rdf(x). Write X⋆=argminx∈Rdf(x) for the minimizer set and ∥⋅∥ for the Euclidean norm. The algorithm receives the nonnegative integer d, the constants L,μ,D,ε, and x0∈Rd.

Our assumptions:

Assumption 1 (Convexity and Lipschitz continuity). For every x,y∈Rd and t∈[0,1], f((1−t)x+ty)≤(1−t)f(x)+tf(y),|f(x)−f(y)|≤L∥x−y∥.

Assumption 2 (Initial distance and sharpness). There exists x⋆∈X⋆ with ∥x0−x⋆∥≤D. For each x∈Rd, there exists z∈X⋆ such that f(x)−f(z)≥μ∥x−z∥.

At any query point x∈Rd, the oracle returns (f(x),g(x)), where g:Rd→Rd is a fixed selection satisfying the subgradient inequality f(y)≥f(x)+⟨g(x),y−x⟩,x,y∈Rd. After the allotted oracle calls, the output must have an integrable objective gap satisfying E[f(x¯)−f(x⋆)]≤ε.

Results

  • Sharp Lipschitz Convex Restarted Subgradient · Lean proof

Convex, L-Lipschitz f:Rd→R with dist(x0,X∗)≤D and global weak sharpness f(x)−f∗≥μdist(x,X∗), where 0<μ≤L and D>0. Each oracle reply gives the exact value and a subgradient. The target is E[f(x^)−f∗]≤ε for ε>0. The displayed upper bounds give this gap guarantee deterministically.
