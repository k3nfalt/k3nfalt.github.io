High-Dimensional Hessian-Lipschitz PL Minimization

We consider minimizing a possibly nonconvex function f:Rd→R in dimension d. Its Hessian is H-Lipschitz, and it satisfies the Polyak–Łojasiewicz inequality with constant μ>0. The objective gap from the origin to a global minimizer x⋆ is at most Δ, with H>0 and 2160≤H2Δ/μ3≤d. At each query point, the oracle returns the exact value, gradient, and Hessian of f. For a tolerance 0<ε≤Δ/32, the goal is a measurable output x¯∈Rd with integrable gap satisfying E[f(x¯)−f(x⋆)]≤ε, where the expectation is over the algorithm’s randomness.

The optimization problem is minx∈Rdf(x). The algorithm receives d∈N and the real parameters H,μ,Δ,ε. The starting point is fixed at x0=0. We use the Euclidean norm ∥⋅∥ and its induced operator norm ∥⋅∥op.

Our assumptions:

Assumption 1 (Lipschitz Hessian). The function f and its gradient are Fréchet differentiable everywhere. At each x∈Rd, the Hessian ∇2f(x) is a linear operator on Rd, and for every x,y∈Rd, ∥∇2f(x)−∇2f(y)∥op≤H∥x−y∥.

Assumption 2 (Initial gap and gradient dominance). There exists a global minimizer x⋆∈Rd such that f(x0)−f(x⋆)≤Δ,2μ(f(x)−f(x⋆))≤∥∇f(x)∥2for every x∈Rd.

A query at any x∈Rd returns (f(x),∇f(x),∇2f(x)). After the allotted oracle calls, the output x¯ must be measurable, the gap f(x¯)−f(x⋆) must be integrable, and its expectation must satisfy E[f(x¯)−f(x⋆)]≤ε.

Results

  • Hessian Lipschitz PLLower Bound · Lean proof

On Rd, f has an H-Lipschitz Hessian in operator norm, an attained minimum f⋆, initial gap f(0)−f⋆≤Δ, and satisfies 2μ(f(x)−f⋆)≤∥∇f(x)∥2 globally. All parameters are public. Each joint query returns exact (f,∇f,∇2f) at one point. The target is a measurable output X with integrable gap and ∫(f(X)−f⋆)dP≤ε under the algorithm’s seed law P. Here H,μ,ε>0, 32ε≤Δ, and 2160≤A≤d.
