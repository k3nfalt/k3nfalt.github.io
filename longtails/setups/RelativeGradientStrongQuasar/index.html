Strong Quasar Minimization with Relative Errors

We consider minimizing a differentiable function f:E→R on a finite-dimensional real Hilbert space E. The function has an L-Lipschitz gradient, with L>0, and is strongly quasar-convex with parameters μ>0 and γ∈(0,1] relative to a global minimizer x⋆. A given point x0∈E satisfies f(x0)−f(x⋆)≤Δ, where Δ≥0. The oracle returns a fixed measurable vector g(x) satisfying ∥g(x)−∇f(x)∥≤δ∥∇f(x)∥, with δ∈[0,1). For ε>0, the goal is an output x¯∈E with integrable objective gap and EP[f(x¯)−f(x⋆)]≤ε, where P is the law of the algorithm’s randomness.

The optimization problem is minx∈Ef(x). The norm ∥⋅∥ is induced by the inner product ⟨⋅,⋅⟩ on E. The algorithm receives E, L, x0, μ, γ, δ, Δ, and ε.

Our assumptions:

Assumption 1 (Smoothness). The function f is Fréchet differentiable everywhere on E, and ∥∇f(x)−∇f(y)∥≤L∥x−y∥,x,y∈E.

Assumption 2 (Strong quasar-convexity and initial gap). There exists x⋆∈E such that f(x⋆)≤f(x),x∈E,f(x0)−f(x⋆)≤Δ. Relative to this same minimizer, strong quasar-convexity means that, for every x∈E, f(x⋆)≥f(x)+1γ⟨∇f(x),x⋆−x⟩+μ2∥x−x⋆∥2.

Assumption 3 (Relative gradient error). The oracle returns g(x) at any query point x∈E, where g:E→E is a fixed Borel-measurable map satisfying ∥g(x)−∇f(x)∥≤δ∥∇f(x)∥,x∈E.

After the allotted oracle calls, the output must have an integrable objective gap under P and satisfy EP[f(x¯)−f(x⋆)]≤ε.

Results

  • Accelerated Relative Quasar · Lean proof

On a finite-dimensional real Hilbert space with its Borel measurable structure, f has an L-Lipschitz gradient and a minimizer x⋆ satisfying f(x0)−f(x⋆)≤Δ and f(x⋆)≥f(x)+γ−1⟨∇f(x),x⋆−x⟩+μ2∥x−x⋆∥2 for all x. Here L,μ,ε>0, 0<γ≤1, Δ≥0, and 0≤δ<1. Each oracle call returns the same measurable g(x), with ∥g(x)−∇f(x)∥≤δ∥∇f(x)∥. Target: ∫(f(xK(ω))−f(x⋆))dP(ω)≤ε, with integrable gap and P the algorithm’s randomization law. The setup does not restrict the algorithm; (1) constructs a randomized continuized method.
